Legacy Sports Media

Legacy Sports Media covers Alabama high-school sports. We built the platform behind it: public site, scoreboard, standings, and the admin the staff publishes from.

The problem

Local sports coverage is scattered across social posts and box scores. Legacy wanted one destination for Friday nights — scores, stories, rankings, and shows — that their staff could update themselves.

What we built

A statewide scoreboard, standings by classification, a stories newsroom, podcasts and video, school pages, and interactive features like weekly pick’em. Behind it is an authenticated admin for live scores, stories, rankings, podcasts, and schools. The database holds more than 600 Alabama schools.

How it is built

Next.js on Vercel with a Supabase Postgres database. Row-level security means the public can read published content only, and the scores table streams updates in real time.
