The problem

Bookings came in through calls and messages, and there was no single place to see what was requested, what was confirmed, and which van was going where.

What we built

A public site with fleet photo carousels and pages for weddings, airport transfers, game days, and corporate travel. Every booking request lands in an owner dashboard where it can be accepted or declined, with a calendar filtered by vehicle. New requests also send email alerts to the owners.

How it is built

A fast static front end on Vercel, serverless API routes, a Supabase database, and transactional email through Resend. Service pages and FAQs carry structured data so they show up well in local search.
