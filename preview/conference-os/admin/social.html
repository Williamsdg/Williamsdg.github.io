Module 09 · Operator Reference

Social Listening.

Real-time ingest from X / Reddit / TikTok / sports media filtered to monitored entities (officials, crews, replay centers, conference). Sentiment scored. Spikes auto-route to Incidents.

09.1

Spike Alert banner

REAL-TIME

Top-of-page red strip when any monitored entity has Tier-1 or Tier-2 mention spike with negative sentiment.

Data Sources

  • Mention firehose (X · Reddit · TikTok · sports media crawl)
  • Per-entity baseline (rolling 30-day window)
  • Sentiment score from fine-tuned model
  • Verified-voice amplification multiplier

Manual Inputs

  • VP Comms clicks "View Cluster" to drill in
  • "Draft Comms Brief" to enter mitigation workflow

Configurable Controls

  • Tier-1 threshold (default sentiment ≤ −0.65 + ≥ 15× baseline + verified amp)
  • Tier-2 threshold (default sentiment ≤ −0.65 + ≥ 10× baseline)
  • Per-entity threshold overrides (calibrated against own baseline)
  • Bot-filter aggressiveness

Permissions & Audit

VP Comms primary. Whitfield daily digest. Schools see school-scoped only. Tier-1 page audit + Incident creation logged.

09.2

Live Mention Feed

REAL-TIME

Most recent mentions, sortable by sentiment + reach. Click row to action.

Data Sources

  • X Enterprise API — full firehose w/ filters (real-time)
  • Reddit API — r/CFB, r/SAC, school subs
  • TikTok Research API
  • Web crawl — The Athletic, Vista, On3, AL.com, Bleacher
  • Broadcast closed-captions — SACN + Vista clip outputs

Manual Inputs

  • Draft Brief / Add to Cluster / Route to Comms / Crisis Flag

Configurable Controls

  • Source toggle (X / Reddit / TikTok / web / broadcast)
  • Min reach to surface (default 500)
  • Min sentiment magnitude
  • Auto-suppress flagged bots (default on)

Permissions & Audit

VP Comms + Comms team. Each manual action logged.

09.3

Crew Mention Volume (per-entity sparklines)

REAL-TIME

Right rail showing mention volume + sentiment per crew over last 24h.

Data Sources

  • Entity-grouped mention counts from firehose
  • Sentiment composite per entity

Manual Inputs

Click → entity profile drilldown.

Configurable Controls

  • Sort order (volume default · sentiment · spike %)
  • Window (default 24h)
  • Max entities shown

Permissions & Audit

VP Comms + VP Officiating. Crew-level data sensitive — restricted.

09.4

Topics & Clusters · Volume Bars · Sentiment Trends

REAL-TIME

Trending phrase cloud + 24h volume bars per entity + 7-day sentiment trend per entity.

Data Sources

  • NLP cluster output (phrase extraction nightly + live append)
  • Hourly volume buckets per entity
  • Daily sentiment averages

Manual Inputs

Pure read. Click cluster → see all mentions.

Configurable Controls

  • Cluster min size to surface
  • Trend display window
  • Cluster algorithm (default topic-based, can switch to entity-based)

Permissions & Audit

VP Comms full. Other roles aggregate only.

09.5

Verified Voices watchlist

EVENT

62 tracked accounts (Finley, Thamel, Vista, The Athletic, etc.) prioritized Priority 1/2/3 with paging rules.

Data Sources

  • verified_voices table — handle + priority + paging rule
  • Real-time match against incoming mentions

Manual Inputs

  • Add voice (handle + priority)
  • Edit priority
  • Remove voice

Configurable Controls

  • Per-priority paging rule
  • Min follower threshold to suggest add
  • Auto-add suggestions from new spike sources

Permissions & Audit

VP Comms edits. All edits logged.

09.6

Alerts & Routing rules + Auto-Drafted Comms Brief

EVENT

14 active routing rules (crew spike → Incidents · sentiment drop → Comms · verified mention → Whitfield digest · etc.) + auto-drafted Comms Brief for any Tier-2+ event.

Data Sources

  • routing_rules — IF condition THEN route
  • Comms Brief generated by LLM with cluster summary + recommended response

Manual Inputs

  • Admin defines routing rules
  • VP Comms reviews + approves brief (Approve & Send, Edit, Suppress)

Configurable Controls

  • Rule editor (admin)
  • Brief template library (per situation)
  • Auto-send on approval (default off — human required)

Permissions & Audit

VP Comms approves. Every rule fire + brief generation + approval/suppression logged.
