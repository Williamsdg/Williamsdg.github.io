Module 12 · Operator Reference

School Portal.

Per-school scoped front door into the platform. Composes per-school slices of every other module. The Quick-Submit drawer is the write-path; everything else is read.

12.1

School switcher dropdown

USER

Top-right dropdown with all 14 SAC schools. Picking a school updates the entire portal scope.

Data Sources

  • schools table — name, mark, color, director, liaison, SA count
  • Per-school identity scope from auth layer

Manual Inputs

  • SAC admin sets per-school metadata (director, liaison, color)
  • User clicks switcher to swap context (SAC office only — schools fixed to own)

Configurable Controls

  • School metadata editor (admin)
  • Default school per user role
  • Mark color override

Permissions & Audit

SAC office can switch any school. School users locked to own. Switch action logged for audit.

12.2

SAC Response Time panel

DAILY

The "what's the SAC owe me back?" surface — avg response time, overdue count, in-SLA %.

Data Sources

  • Computed from every school-side request across modules (Film Portal, Credentialing, Travel, Compliance)
  • Each request's SLA window vs. SAC response time

Manual Inputs

None — auto-computed.

Configurable Controls

  • SLA windows per request type (default 72h film, 48h cred, 5d travel, etc.)
  • Rolling window for avg (default season)
  • Overdue threshold

Permissions & Audit

School + SAC office sees school-scoped. Aggregate across schools visible to VPs only.

12.3

Activity-by-sport (filterable list)

REAL-TIME

All conference activity touching this school, filterable via sport-bar. Spring postseason today, FB recruiting tomorrow.

Data Sources

  • Aggregated from Scheduling (events), Officials (assignments), Film Portal (submissions), Compliance (acks), Travel
  • Per-row sport tag drives filtering

Manual Inputs

None on this page — items born in source modules.

Configurable Controls

  • Sport-bar visibility per role
  • Row sort order
  • Max items per sport before "show more"

Permissions & Audit

School-scoped only. Each row click opens source module with school filter applied.

12.4

Open Requests (Westbrook → SAC)

REAL-TIME

Active outbound requests from this school: type, age, SLA status (OVERDUE / IN REVIEW / CONFIRMED / etc.).

Data Sources

  • Joined view of: Film Portal submissions, Credential requests, Travel requests, Ops requests, Compliance submissions
  • SLA color computed per row

Manual Inputs

  • School Sport Ops Director submits via Quick-Submit drawer
  • Status updates auto-driven by SAC team action upstream

Configurable Controls

  • Default filter (Open · Closed · All)
  • SLA threshold colors
  • Auto-snooze closed items

Permissions & Audit

School + SAC reviewers. School-scoped. WORM via the source modules.

12.5

Sport Status cards (8)

DAILY

Per-sport live status: record, current event, next event.

Data Sources

  • Per-school sport status from athletic record feeds + Scheduling
  • Live = computed (live if game today, upcoming if game in 14d, else offseason)

Manual Inputs

Records updated by school comms team in Media Hub.

Configurable Controls

  • Which 8 sports surface (priority order per school)
  • Card content per sport

Permissions & Audit

School edits own. SAC views all schools.

12.6

Upcoming Events + Conference Comms

EVENT

Next 14 days of conference-coordinated events for this school + recent SAC office threads tagged with this school.

Data Sources

  • Events — Scheduling filtered to school
  • Comms — Comms Hub channels + DMs tagged to this school

Manual Inputs

None on this page. School ack on Comms threads via Comms Hub.

Configurable Controls

  • Date window (default 14d)
  • Comms channel inclusion list
  • Notification rules

Permissions & Audit

School + SAC. School-scoped.

12.7

Quick-Submit drawer (6 forms)

USER

The portal's primary write-path. 6 forms: Credentials · Travel · Media Availability · Compliance Submission · Film Upload · Incident Report.

Data Sources

  • Each form writes to the corresponding source module's submission table
  • Auto-routes to the SAC team for that workflow
  • SLA clock starts on submit

Manual Inputs

  • School user fills form (event, recipients, count, dates, description, attachments)
  • Submit triggers email + Comms Hub thread + record creation

Configurable Controls

  • Form-field config per request type (admin)
  • Routing rules per request type
  • Required-field enforcement
  • Per-form SLA window

Permissions & Audit

School users + AD. SAC routing-recipient auto-set. Every submission WORM-logged with full form snapshot.
