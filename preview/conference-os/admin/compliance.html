Module 11 · Operator Reference

Compliance & Governance.

Two jobs: workflow (self-reports + interpretive requests + NCAA submissions) and audit trail (every consequential action in every module, 7-year WORM retention per NCAA Bylaw 32.7).

11.1

Open Compliance Cases

EVENT

Active workflow queue with severity (L-I through L-IV), routing status, owner.

Data Sources

  • compliance_cases — submitted by schools or auto-opened from system events
  • Severity classification rules per bylaw
  • Routing computed from severity + sport

Manual Inputs

  • School compliance lead submits self-report
  • SAC compliance team triages + routes
  • Reviewer adds findings + outcome

Configurable Controls

  • Severity classification rules (admin)
  • SLA per severity (default L-I = 14d, L-II = 30d, L-III = 60d, L-IV = 90d)
  • Auto-escalation thresholds

Permissions & Audit

VP Compliance + Sport Coordinators triage. Legal counsel escalation. School submits + sees own. Every action WORM-logged.

11.2

Policy Acknowledgment heatmap (14 schools)

REAL-TIME

Per-school ack % across all active policies — colored green ≥ 90%, yellow 80-89%, red < 80%.

Data Sources

  • Comms Hub ack reactions + in-app acks (composite signal)
  • Per-policy per-school per-user ack tracking

Manual Inputs

  • School compliance leads ack memos via Comms Hub or in-app
  • SAC sends reminders on cell click

Configurable Controls

  • Color cutoffs
  • Required-ack window per policy (default 14d)
  • Auto-reminder cadence

Permissions & Audit

VP Compliance + SAC office full. Schools see own row only. Every ack signal WORM.

11.3

Policies & Memos library

EVENT

Active policy + memo list with version, sent date, ack-rate.

Data Sources

  • policies + memos tables — versioned, immutable after publish
  • Distribution log per memo (who received, who ack'd)

Manual Inputs

  • VP Compliance + Sport Coordinators draft policies/memos
  • Distribution targeted by role + sport + school

Configurable Controls

  • Version policy (admin)
  • Auto-archive old versions (default retain all)
  • Distribution channels (Comms Hub, in-app, email)

Permissions & Audit

VP Compliance edits. Sport Coords draft. All recipients see relevant items. Every send + ack WORM.

11.4

Education Modules (12 required)

EVENT

Annual training modules per school + per role. Completion rates per module.

Data Sources

  • edu_completions — user_id + module_id + completed_at
  • Native module runner with quiz scoring

Manual Inputs

  • Users complete modules in-app
  • VP Compliance authors new modules

Configurable Controls

  • Annual deadline (default 12/15)
  • Per-role required module list
  • Refresher cadence per module
  • Pass threshold per quiz

Permissions & Audit

VP Compliance manages. Per-user completion tracked. WORM.

11.5

NCAA Submission Log

EVENT

Outbound queue to NCAA: self-reports, interpretive requests, bylaw certifications. Cycle time tracked.

Data Sources

  • NCAA submission API (or email fallback)
  • NCAA portal response → status update

Manual Inputs

  • SAC compliance drafts each submission
  • NCAA response parsed + status updated
  • Revisions if NCAA returns

Configurable Controls

  • Submission templates per bylaw type
  • Auto-route to legal for review (severity-based)
  • NCAA portal credential management

Permissions & Audit

VP Compliance + legal review + Commissioner sign-off for L-I. Every submission WORM.

11.6

Audit Trail (universal log)

REAL-TIME

Every consequential action across all 12 modules. Searchable + filterable + exportable. WORM 7-year retention.

Data Sources

  • Every module writes audit_events rows
  • Stored in WORM-tier S3 with cryptographic hash chain
  • Indexed in audit_index for search

Manual Inputs

None — automatic from every module action.

Configurable Controls

  • Filter UI: event type, actor, module, date range
  • Export formats (CSV, JSON, PDF)
  • Retention policy (default 7yr, can extend per type)

Permissions & Audit

VP Compliance + legal counsel. External auditors via time-limited grants. Every audit-trail query itself logged.
