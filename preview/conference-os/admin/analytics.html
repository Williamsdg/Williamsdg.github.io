Module 10 · Operator Reference

Executive Analytics.

Pure downstream module — every number here lives in another module. This is the composed board-level view. Nothing is born here. Editing flows live in the upstream module.

10.1

Big KPI tiles (4)

DAILY

Total Attendance · Avg FB Rating · Media Revenue · Officiating Accuracy. Big tiles with sparklines + YoY delta.

Data Sources

  • Attendance — school ticketing systems → Scheduling event totals → roll-up
  • Ratings — Mediascore + streaming partner reports
  • Revenue — SAC finance booked-revenue feed
  • Officiating accuracy — Officials grading engine composite

Manual Inputs

Nothing on this page. Upstream finance team enters monthly revenue settlements.

Configurable Controls

  • Which 4 KPIs shown (admin choice from ~15 available)
  • Sparkline window (weekly default, monthly toggle)
  • YoY vs YTD comparison default

Permissions & Audit

Commissioner + executive committee + VPs. No edit — pure read.

10.2

Attendance · stacked bar chart

DAILY

Per-week stacked bars by school grouping (East home, West home, cross-divisional, rivalry).

Data Sources

  • School ticketing API → per-game gate count → grouping rule from event_type

Manual Inputs

None — auto-grouped.

Configurable Controls

  • Grouping rule (default east/west/cross/rivalry, can swap by venue)
  • Date range (default season)

Permissions & Audit

All executive roles view.

10.3

Officiating Accuracy YTD trend

DAILY

Weekly composite officiating grade across all crews + sports.

Data Sources

  • Officials grading engine — weekly aggregate
  • Cutoffs: ≥ 92 green, 88-92 yellow, < 88 red

Manual Inputs

None — driven by Officials module grade publishing.

Configurable Controls

  • Cutoff thresholds tunable per sport
  • Window (default season)

Permissions & Audit

VP Officiating + Commissioner. Sport admins see own sport.

10.4

Top Crews Leaderboard · Revenue Donut · Ops Health gauges

DAILY

3 bottom panels — leaderboard (FB crews), revenue mix donut, and Operations Health bars (incident response · replay ruling · film SLA · travel on-time · officials confirm · championship workstream).

Data Sources

  • Leaderboard — Officials YTD grades
  • Donut — finance revenue mix (media rights · championships · sponsorship · licensing)
  • Ops Health — composite of incident time-to-ack, replay avg time, film SLA hit-rate, travel on-time, confirmations, championship workstream %

Manual Inputs

None.

Configurable Controls

  • Leaderboard top-N (default 7)
  • Revenue category labels editable
  • Ops Health KPI choices (admin selects which 6-8 surface)

Permissions & Audit

Read-only. Commissioner + committee + VPs.

10.5

Export PDF Brief · Schedule Board Pack

USER

One-click export to PDF for board meetings. Scheduled board-pack automation.

Data Sources

  • Renders current page state to PDF via headless browser
  • Optional commentary fields editable in Comms

Manual Inputs

  • Comms VP writes commentary block per quarter
  • Director can adjust date range + filters before export

Configurable Controls

  • PDF template (logo, footer, branded)
  • Auto-schedule to executive committee monthly
  • Distribution list

Permissions & Audit

Commissioner + VPs. Every export logged with recipient list.
