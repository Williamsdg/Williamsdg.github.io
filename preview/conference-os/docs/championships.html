Module 06 · Operations Suite

Championship Management.

The 18-workstream project-management surface for every SAC championship — venue, hotels, security, hospitality, ticketing, volunteers, broadcast, transportation. Run all 21 championships in parallel, with one source of truth per event.

01 · WHAT IT DOES

One project view, per championship.

A championship is a 6-month project. The SAC Football Championship has 18 workstreams (venue ops, broadcast, ticketing, credentialing, security, hospitality, transportation, volunteers, ADA, media workroom, FanFare activation, etc.). Today these live in spreadsheets, PowerPoints, and email threads. This module makes them one shared, color-coded board.

Each championship has its own page with a workstream board (Green / Yellow / Red status), a countdown timer to event day, hotel-block pickup tracking, volunteer onboarding bars by role, ticketing distribution, and joint-command coordination with local LE and EMS. When a workstream goes red — like the SACCG vendor swap currently underway — the system surfaces it everywhere it touches: incident desk, executive analytics, daily leadership brief.

02 · WHO USES IT

Owned by the Director of Championships · executed by an event team.

  • Director of Championships — primary owner across all 21 events.
  • Event-specific operations team (per championship) — assigned to each workstream.
  • Host school operations — co-owner when the championship is hosted at a campus site.
  • Joint command (SACP, local PD, EMS) — visibility into the security/medical workstreams.
  • Vendors — limited contractor access via invited links (catering, transportation, etc.).

04 · MONITORING APPROACH

The countdown rhythm.

T-6 months → T-1 month

Director reviews the workstream board weekly. Yellows escalate to Director. Reds escalate to the Commissioner's office.

T-30 days → T-7 days

Daily standup against the board. Hotel block pickup checked daily; release deadlines monitored. Volunteer onboarding pushed to 100%.

T-7 days → T-0

Joint command walkthrough. Vendor confirmations. Ticketing readiness check. Whitfield briefing. Wall-mode display in the championship ops room.

T+24 hours

After-action report auto-drafted from the board. Lessons captured to the template for next year.
