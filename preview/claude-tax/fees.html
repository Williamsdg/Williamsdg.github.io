Worksheet BExtensions

What does an extension cost?

If you request an extension, a non-refundable fee is required. It is 50% of your prior year’s tax preparation fee, payable when the extension request is submitted.

$
Extension fee, due with the request$100.00

This amount is applied toward your preparation fee if your return is completed by this office. An extension to file is not an extension to pay any taxes owed.
