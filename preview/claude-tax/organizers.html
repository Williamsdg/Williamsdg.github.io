QuestionID requirement

Do I need a driver’s license or state ID number to file a return?

You do need a driver’s license number or a government-issued ID (state ID, student ID and so on) to file a federal return.

Some states may request your driver’s license number for state tax returns because they have the ability to match state records and help confirm your identity. This is one more layer of protection against identity thieves. State tax software will prompt you for your driver’s license number in order to e-file.
