04 / How an Assignment Works

A simpler way to handle
complicated claims.

Four steps, one point of contact, and a report your file can actually use.

01

Submit

Send the assignment, the file documentation and the contact for the unit. Anything you already have helps; we’ll ask for the rest.

02

Review

Cornerstone evaluates the loss and assigns the right expertise — equipment, commercial, auto or consulting.

03

Inspect

An experienced appraiser handles the physical inspection, teardown coordination and documentation.
