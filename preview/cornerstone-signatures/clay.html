  1. In Gmail, click the gear (top right) → See all settings.
  2. Scroll down to Signature → Create new. Name it Cornerstone.
  3. Click in the big empty box and press ⌘V (Mac) or Ctrl+V (Windows).
  4. Underneath, set For new emails use and On reply/forward use to Cornerstone.
  5. Scroll to the bottom and click Save Changes.
If step 4 is skipped the signature will never show up. Both dropdowns start on “No signature”.
