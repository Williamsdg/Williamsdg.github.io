Customizing for a real HOA prospect

When you're ready to pitch a specific client, duplicate this whole directory and replace the Briarwood tokens with the prospect's actual details.

Recommended workflow

  1. Copy the entire hoa-pitch-template/ directory to a new folder named after the client (e.g., oakhaven-pitch/).
  2. Run a find-and-replace across all files for the bulk tokens below.
  3. Edit mock-data.js to set the actual home count, neighborhood names, and staff personas for that client.
  4. Update the email subjects in mailto links to mention the client by name.
  5. Open pitch.html in a browser and walk through every section to catch any stragglers.

Money math (recalculate per prospect)

The savings comparison ($14K–$51K vs AppFolio) scales linearly with home count. For a new prospect at N homes, multiply N by $1.40 (low) and $5.00 (high) to get the annual AppFolio range. Your Williams Digital annual ($3.6K–$9K depending on tier) stays the same regardless of home count — that's the whole pitch.
