Why this page exists

On the Town's current website, an ordinance link does not open the ordinance. It opens a 115 KB web page that then loads Adobe's viewer to display the file. Here is the difference, measured on the live site today.

Today

  • Every ordinance link loads a full web page plus a third-party PDF viewer before a word appears
  • Every one of those pages is titled "Town of Decatur - Home" — so bookmarks, browser tabs and screen readers all say the wrong thing
  • No way to right-click and save, and no plain file link exists anywhere on the platform
  • The list itself is held together by a hand-written script that reaches into the vendor's code — one vendor update and the page goes blank
  • Nothing is in the page source, so none of the 54 ordinances can be found by search

This concept

  • The link is the document. One click, one file, straight to the phone or desktop
  • Each ordinance gets its own real page title and web address
  • Two views, switched instantly — plain list or searchable library
  • Nothing depends on a vendor's internal code, so nothing silently breaks
  • Ordinance text is readable as a web page, so residents find it by searching, and it meets the 2028 accessibility rule
