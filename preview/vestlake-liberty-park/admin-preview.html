What the Admin Can Do

Designed for the board, not developers

Everything a board secretary or volunteer needs — no more.

Upload Newsletters

Drop a PDF, fill in three fields, publish. Archive page updates itself with proper sorting by date.

Manage Calendar Events

Add board meetings, social events, pool open/close dates, trash holidays. Pick a date, type a title, save.

Post Documents

Upload board minutes, bylaws, financial reports. Organize into categories. Replace or remove anytime.

Edit the Homepage Banner

Change the welcome message, announcement banner, or featured event with a single text field.

Update External Links

Switching dues provider, ARC system, or pool reservation tool? Change one URL and the whole site updates.

Add Board Members

Invite a new board secretary by typing their GitHub username. Remove access just as easily when terms end.

How Publishing Works

Click "publish" and it's live in under a minute

Under the hood — but you never have to think about any of this.

1

You edit content

Type, upload, save. Same as Gmail or Google Docs.

2

Saved to GitHub

Every edit is version-controlled. You can undo any change.

3

Site rebuilds

GitHub automatically rebuilds the public website with your edit.

4

Live worldwide

~60 seconds later, residents see the update.
