LEGACY SPORTS MEDIA
DNS Setup · About 5 Minutes

Point the Domain to the New Website

Hey Charles — since the domain lives in your GoDaddy account, this quick change on your end connects it to the new Legacy Sports Media site. Two small edits, done.

legacysportshq.com

Log in to GoDaddy

Go to godaddy.com and sign in with the account that owns the domain.

Open the DNS settings

Tap your name (top right) → My Products. Find legacysportshq.com and click the three dots (⋯) next to it → Manage DNS.

You'll see a list called DNS Records.

Edit the “A” record

Find the row where Type = A and Name = @ (it usually says “Parked”). Click the pencil ✏️ to edit it and set it to exactly this:

TypeNameValueTTL
A@76.76.21.21Default (1 Hour)
No A record with “@”? Click Add New Record instead and create it with the values above.

Edit the “www” record

Find the row where Type = CNAME and Name = www. Edit it to point to:

TypeNameValueTTL
CNAMEwwwcname.vercel-dns.comDefault (1 Hour)
If it doesn't exist: Add New Record → CNAME → www → the value above.

Turn off forwarding (if it's on)

Still on the DNS page, look for a Forwarding section near the bottom. If the domain is being forwarded anywhere, delete the forward — it fights with the new records.

Save — that's it

Save the records and you're done. It usually goes live within 10–30 minutes (occasionally a few hours). Dylan gets an automatic confirmation when it connects, and the new site will load at legacysportshq.com.

Shoot Dylan a text when you've saved it so he can watch for it. 👍

Please don't change these

  • Nameservers — leave them exactly as they are (ns35/ns36.domaincontrol.com)
  • Any MX or TXT records already in the list
  • Anything else you're not sure about — when in doubt, ask Dylan first

Only Two Records Change

A record @ → 76.76.21.21 and CNAME www → cname.vercel-dns.com. Everything else stays the same.
