Module 07 · Operator Reference

Media & Content Hub.

Asset library + broadcast coordination layer. Video lives in Mux, audio in S3, photos in Cloudinary. CDN egress and partner SLAs tracked here.

07.1

Latest Asset Drops (gallery)

EVENT

3-column thumbnail grid of last 12 asset packages (b-roll, highlights, photo, graphic, audio, live feed).

Data Sources

  • asset_packages table with metadata (type, sport, duration, quality)
  • Mux thumbnails auto-generated
  • Live feeds from CDN egress monitor

Manual Inputs

  • SEC comms / school comms uploads
  • Asset metadata tagging (sport, event, talent)

Configurable Controls

  • Auto-transcode quality presets (HD / 4K / mobile)
  • Thumbnail style (default frame at 1s)
  • Default sort (newest first)
  • Type filter chips

Permissions & Audit

SEC comms team upload + edit. Schools upload own. Partners download. Every download logged for SLA tracking.

07.2

School Content Packages

EVENT

Weekly package distribution per school (16). Status: delivered / queued / failed.

Data Sources

  • school_packages — weekly compiled asset bundle per school
  • Delivery method per school (CDN pull · S3 push · sftp)

Manual Inputs

  • Package composition rules per week
  • Re-deliver on request

Configurable Controls

  • Package contents rule per school
  • Delivery schedule (default Friday 6am)
  • Retry policy on failure

Permissions & Audit

SEC comms manage. Schools receive + view their own. All delivery attempts logged.

07.3

Broadcast Windows

REAL-TIME

Per-partner live status (CBS, ABC, ESPN, SECN, SECN+). ON / HALF / UP NEXT / CLOSED.

Data Sources

  • Partner ops push to broadcast_windows via API
  • SECN direct integration
  • Fallback: SEC liaison manual entry

Manual Inputs

  • Window definition entered weeks ahead in Scheduling
  • Partner ops marks ON AIR / HALF / OFF
  • SEC liaison status override on partner outage

Configurable Controls

  • Auto-flag feed-loss incident at threshold (default 5 min hung status)
  • Per-partner status push frequency
  • Streaming windows on/off (SECN+, Paramount+)

Permissions & Audit

Partners write. SEC liaison + Comms VP edit. Status changes logged.

07.4

Press Archive + transcripts

EVENT

Every sanctioned press session captured + transcribed within 30 min of end. Searchable.

Data Sources

  • SEC AV capture — automated record on session start
  • Transcription vendor (e.g., Otter/AWS Transcribe) — async, 30 min target
  • Full-text search indexed in press_archive

Manual Inputs

  • Session metadata (subject, sport, school) by Comms team
  • Transcript human-review for high-stakes sessions

Configurable Controls

  • Auto-publish vs human-review per session type
  • Search retention window (default 5 years)
  • Talent name dictionary for transcription accuracy

Permissions & Audit

Comms full edit. SEC roles + partners view published. Internal-only flagged with restricted-access. Every edit logged.

07.5

Talent & Sideline assignments

EVENT

Per-game talent (sideline reporters, analysts, hosts) with live on-air status.

Data Sources

  • Network ops feeds per partner
  • SEC comms internal cross-reference
  • Live status = network broadcast metadata

Manual Inputs

Network ops fills initial roster; SEC liaison can adjust.

Configurable Controls

  • Per-network roster sync cadence
  • Default talent display (name + role default)

Permissions & Audit

Partners + SEC comms. Edits logged.

07.6

Sponsor Assets & Deliverables

EVENT

Per-sponsor deliverable workflow (Dr Pepper, Coca-Cola, etc.) with delivery status + deadline tracking.

Data Sources

  • sponsor_deliverables tied to sponsor_contracts
  • Delivery confirmation from sponsor portal

Manual Inputs

  • Contracts entered by Partnership team annually
  • Per-deliverable upload by Comms
  • Sponsor approves/rejects via portal

Configurable Controls

  • Deadline reminders (7 / 3 / 1 day defaults)
  • Auto-escalation rules

Permissions & Audit

SEC Partnership team + Comms. Sponsors limited to their own. Every approval/rejection logged.
