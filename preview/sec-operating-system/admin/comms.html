Module 04 · Operator Reference

Staff Comms Hub.

Slack-class workspace with role-gated channels, WebRTC voice rooms, and immutable message retention. Auto-posts from other modules use a bot identity. Every section, every input, every control below.

04.1

Channel rail (left sidebar)

EVENT

Channels grouped by Starred · Football Ops · Other Sports · Conference Office · DMs. Game-weekend channels open/archive automatically.

Data Sources

  • channels + memberships tables
  • Auto-channel triggers: Scheduling pushes game records 48h pre-kick
  • Membership filtered by user's role + sport + school

Manual Inputs

  • Admin creates standing channels
  • User stars channels (per-user setting)
  • Admin adds/removes members

Configurable Controls

  • Auto-channel open window (default 48h pre-kick)
  • Auto-archive after (default 24h post-game)
  • Channel category collapse default (Starred + DMs always open; others remember user choice)
  • Channel naming convention

Permissions & Audit

Channel access = identity layer (role + sport + school). Create/delete logged. Membership changes logged.

04.2

Message stream (main pane)

REAL-TIME

Live messages with threading, reactions, attachments, and bot auto-posts (replay rulings, incident alerts, memo distributions).

Data Sources

  • messages table — immutable, WORM-tier
  • reactions + threads tables
  • Bot identity = system user with module attribution

Manual Inputs

  • Type → send
  • React with emoji
  • Reply in thread
  • Attach file (uploads to object store, message links it)

Configurable Controls

  • Allowed file types + max size
  • Reaction emoji set
  • Bot post density (auto-post on every event vs. summary)
  • Notification rules per role/channel

Permissions & Audit

Channel members can post + react. Edit/delete restricted to author within 5 min then locked. All messages retained 7 years.

04.3

Voice rooms

REAL-TIME

Always-on for replay-coordination channels (recorded). Standard rooms ephemeral. Active speaker shows gold ring.

Data Sources

  • WebRTC SFU — peer connections + per-user active-speaker signal
  • Recording = SFU writes to encrypted object store (replay-channel rooms only)

Manual Inputs

  • Join Room / Listen Only / Leave
  • Mute self

Configurable Controls

  • Recording policy per channel (default: replay-channels record, others ephemeral)
  • Max simultaneous speakers
  • Audio quality (default 48kHz, can reduce)
  • Auto-transcribe (default on for recorded rooms)

Permissions & Audit

Channel members can join. Recording metadata + transcript WORM. Recording retained 7 years.

04.4

Pinned playbooks & resources

EVENT

Top-of-channel pinned items: game-day playbook, current memos, crew rosters, mic IDs.

Data Sources

  • pinned_items — channel_id + resource_ref
  • Resource_ref can point to Compliance memo, Officials roster, file in object store, etc.

Manual Inputs

  • Admin/channel-owner pins via "📌 Pin" on a message or resource link
  • Auto-pinned on channel create from template

Configurable Controls

  • Max pinned items per channel (default 8)
  • Auto-pin templates per channel type
  • Pin expiration (default never, can set per-pin)

Permissions & Audit

Channel admins pin. Read by all members. Pin/unpin logged.

04.5

Alert blocks (incident-driven)

REAL-TIME

Bot posts a red alert block into relevant channels when an incident opens (weather hold, medical, security). Requires ack reactions.

Data Sources

  • Incidents module — auto-posts when SEV-2+ opens
  • Channel routing = severity + sport + venue
  • Ack tracking = reaction by required roles

Manual Inputs

Recipients click "ACK" reaction.

Configurable Controls

  • Severity threshold (default SEV-2)
  • Ack-required role set per incident type
  • Ack reminder cadence (default 5/10/15 min)
  • Escalation chain on ack-miss

Permissions & Audit

All channel members see. Required-ack roles must react. Ack/no-ack WORM-logged.

04.6

Game Status widget (right rail)

REAL-TIME

In game-weekend channels, right rail shows current game state, attendance, crew, replay center, review count.

Data Sources

Composed read from same sources as Ops Center game tile.

Manual Inputs

None.

Configurable Controls

  • Which game stats shown (default: score, quarter, attendance, crew, replays)
  • Refresh interval (default 10s)

Permissions & Audit

Channel members. Read-only.
