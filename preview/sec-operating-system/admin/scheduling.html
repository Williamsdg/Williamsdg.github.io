Module 05 · Operator Reference

Scheduling & Event Operations.

The master event calendar across 21 sports — system of record for which events exist. Every downstream module (Officials assignments, Comms channels, Credentialing, Travel, Championships) reads from it.

05.1

NCAA Postseason banner + KPI row

REAL-TIME

Top banner contextualizing the current week's biggest themes. 6 KPI tiles: events live, officials assigned, pending confirmations, travel segments, hotel nights, conflicts.

Data Sources

  • Banner text — admin-curated weekly + auto-generated from event count by type
  • KPIs computed from events, assignments, travel_segments, hotel_blocks, conflicts

Manual Inputs

  • Director writes weekly banner override (rare)
  • All KPI components computed

Configurable Controls

  • Banner auto-generation rules (NCAA-week, rivalry-week, championship-week, ordinary)
  • Which 6 KPIs shown (drag-reorder)
  • KPI compute window (default this-week)

Permissions & Audit

Director of Event Ops edits banner. SEC roles view. Banner edits logged.

05.2

Sport Balance tiles

DAILY

14-tile grid at top showing all 21 sports' live/upcoming/offseason status this week.

Data Sources

  • Per-sport event count this week from events
  • Status = computed (live if any event today, upcoming if event in next 14d, else offseason)
  • Sub-label = curated note per sport (NCAA event, offseason activity, etc.)

Manual Inputs

  • Sport ops liaison maintains sub-label note weekly

Configurable Controls

  • Tile order (default alphabetic by category)
  • Status thresholds (live = today, upcoming = ≤ 14d, else offseason)
  • Tile drilldown destination

Permissions & Audit

All SEC roles view. Sub-label edits logged.

05.3

This Week density grid

EVENT

15-row × 7-day matrix showing event density per sport per day. Cells colored by intensity; high = bigger events.

Data Sources

  • events table grouped by sport + day
  • Cell intensity = count + event-type weight
  • Special labels (SECT, NCAA, BYE) from event_type field

Manual Inputs

None for the grid. Events created in Scheduling event editor.

Configurable Controls

  • Date range (default this-week, range 1-2 weeks)
  • Sport row order (admin-tunable)
  • Intensity thresholds (low/regular/high)
  • "Today" highlight on/off

Permissions & Audit

All SEC roles view. Schools see only their sports.

05.4

Saturday multi-sport slate

EVENT

Saturday's events as color-coded tiles by sport. Live status, broadcast, crew, time slot.

Data Sources

  • events + assignments + broadcast_windows
  • Status pulled from Ops Center live state

Manual Inputs

Events authored in event editor. Status auto-driven.

Configurable Controls

  • Sort (kickoff time default, sport, status)
  • Sport color band visibility

Permissions & Audit

All SEC roles view.

05.5

Pending Confirmations · Credentialing · Venues (3 panels)

EVENT

Three bottom panels. Pending Confirmations lists officials/staff who haven't confirmed. Credentialing lists this week's issued/pending. Venues lists active sites.

Data Sources

  • Pending — assignments where status = pending + deadline approaching
  • Credentialing — credential_requests filtered to this week
  • Venues — venues joined to events this week

Manual Inputs

  • Confirmations from officials in mobile app
  • Credentials issued by Credentialing lead
  • Venue gates/status entered by venue ops

Configurable Controls

  • Pending warning window (default 24h)
  • Credential auto-issue rules per type
  • Venue refresh interval

Permissions & Audit

Director of Event Ops + Credentialing lead edit. All ops roles view. Schools see only their venues.

05.6

Annual Sport Calendar (15 × 12)

DAILY

15 sport rows × 12 months grid showing season windows (preseason/regular/postseason/champ). Current month highlighted gold.

Data Sources

  • sport_calendars — one record per sport · season-type · start_month · end_month
  • Cell classification rule-based from sport_calendar entries

Manual Inputs

  • Admin defines sport-calendar entries annually (NCAA / SEC publishes)
  • Adjusted as NCAA calendar changes

Configurable Controls

  • Season window definitions per sport
  • Color-coding rules
  • "Now" highlight method (current month vs current week)

Permissions & Audit

VP-level admin sets calendar; logged annually.

05.7

Other tabs (Staffing · Credentialing · Travel · Venues · Templates)

EVENT

5 deeper-detail tabs, each a focused view of the underlying data.

Data Sources

  • Staffing — joins assignments + people across all event types
  • Credentialing — credential_requests + issuance log
  • Travel — travel_segments + hotel_blocks + cost
  • Venues — venues with this-week event join
  • Templates — event_templates library (26)

Manual Inputs

  • Reassign Shift / Bulk Issue / Travel Desk / Spawn from Template

Configurable Controls

  • Per-tab default sort + filter
  • Template editor (admin)
  • Workflow defaults per event type

Permissions & Audit

Director of Event Ops edit. Schools see their own. Every assignment/credential/travel change logged.
