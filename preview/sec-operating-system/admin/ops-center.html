Module 01 · Operator Reference

Live Game Ops Center.

The composed view of every SEC game on Saturday. Almost no data is born here — the page reads and renders from every other module. This reference walks every visible section: where the data comes from, what (rarely) needs to be entered, what an admin can configure, and who can see or change it.

On this page
  • 1. Needs-Attention strip

  • 3. Game Board
  • 4. Game Detail panel (with sub-tabs)

01.1

Needs-Attention strip

REAL-TIME

Top-of-page strip surfacing only the 2-3 things that need human action right now. When clear, shifts green and reads "All clear." The first thing scanned on game day.

Data Sources

  • Incidents module — auto-pulls SEV-2+ open incidents
  • Replay center system — replays in REVIEWING stage > 60s
  • Social Listening — Tier-2 spike alerts
  • Weather module — active NWS advisories at conference venues

Manual Inputs

None for the strip itself. Items are created in their source modules (Incidents desk for medical/security, Social Listening for spikes). Strip is read-only.

Configurable Controls

  • Max items shown (default 3, range 1-5)
  • Severity threshold (SEV-1, SEV-2, SEV-MON, etc.)
  • Replay stage clock threshold (default 60s)
  • Snooze duration (default 5 min)
  • Auto-clear when all items closed (on/off)

Permissions & Audit

Visible to: SEC Executive, Sport Admin, Replay, Event Staff. Snooze action logged to audit trail with actor + reason. Schools see a school-scoped version (only items affecting their games).

01.2

KPI tile row · 6 tiles

REAL-TIME

Six tiles showing conference-wide ops health: Games Live · Replays in Review · Weather Holds · Incidents Open · Time Since Last Incident · Avg Time-to-Acknowledge.

Data Sources

  • Games Live — count from Scheduling + status from game feed
  • Replays in Review — replay center system, count of open
  • Weather Holds — Incidents module, type=WX
  • Incidents Open — Incidents module total open
  • Time Since Last Incident — computed from incidents log
  • Avg Time-to-Acknowledge — rolling 24h, incidents module

Manual Inputs

None. All metrics computed from upstream modules.

Configurable Controls

  • Which 6 of ~12 available KPIs to show (drag-to-reorder)
  • Threshold colors (good/warn/danger cutoffs per tile)
  • Sport filter (apply sport pill to KPI numerator)
  • Computation window for averages (default 24h, range 1h-7d)

Permissions & Audit

Visible to all SEC office roles. Configuration changes (which tiles shown, threshold cutoffs) restricted to Sport Admin+ and logged.

01.3

Game Board

REAL-TIME

The center of the page. Every SEC game grouped by status (Live · Upcoming · Final). Each row shows score, quarter, crew, venue, attendance, replay/weather/incident icons, color-band team accent, and pin button.

Data Sources

  • Score & clock — Genius Sports live feed (primary), SECSports.com (fallback), WebSocket push, ~2s latency
  • Crew assignment — Officials module (per game)
  • Venue + attendance — Scheduling module + school ticketing APIs (15-min refresh on attendance)
  • Replay icon — Replay center system (live)
  • Weather icon — NWS + venue lightning detection
  • Incident icon — Incidents module count per game

Manual Inputs

None for the board. Score-correction overrides for the feed (rare) are entered upstream in Scheduling's game_events table by the on-duty coordinator + logged.

Configurable Controls

  • Group-by mode (status default · sport · venue · broadcast partner)
  • Sort within group (kickoff time default · attendance · grade)
  • Icon columns (replay / weather / incident / medical — toggle each)
  • Team color band visibility (on/off)
  • Auto-select first live game on load (on/off)

Permissions & Audit

All SEC roles view. School-scoped users see only games involving their school. Pin action user-scoped (each user pins their own); no audit. Manual score override audit-logged with actor.

01.4

Game Detail panel · 4 sub-tabs

REAL-TIME

Right-side drill-in for selected game. Shows matchup card + 4 tabs: Timeline (play-by-play with key events), Officials (7-man crew roster + grades), Replays (this game's reviews), Notes (ops + medical + school).

Data Sources

  • Timeline — composed of: scoring plays (game feed), replay rulings (replay system), incident events (incidents), comms-bot posts
  • Officials tab — Officials module crew roster + live grading engine
  • Replays tab — replay center per-game log
  • Notes tab — Comms Hub messages tagged to game + Incidents notes

Manual Inputs

  • Notes: on-duty coordinator can type a note into the Notes tab — writes to game_notes and posts to #game-weekend channel
  • Timeline "minor event" classification is rule-based but admin can override individual events to major/minor

Configurable Controls

  • Default sub-tab (Timeline default, can change to Replays)
  • "Minor event" rules (which event types collapse by default)
  • Timeline event types displayed (toggle Score / Replay / Incident / Note / Comms)
  • Auto-scroll-to-latest on new event (on/off)

Permissions & Audit

All SEC roles view. Notes write-access: SEC Executive, Sport Admin, Replay Center lead. Every note logged with actor + timestamp + visible-to scope (ops-only vs school-shared).

01.5

Replay Activity panel

REAL-TIME

Every replay review across the conference today, with stage progress bar (Trigger → Review → Confer → Rule → Communicate), elapsed clock, replay center + reviewer name. Click to open Replay Center.

Data Sources

  • Replay center system — Birmingham, Atlanta, Nashville, Dallas + cross-cover sites
  • Per-review: trigger play, stage timestamps, reviewer ID, recommended call, communicated call
  • Push on every stage transition (sub-second latency)

Manual Inputs

  • Reviewer enters ruling text + final call in Replay Center
  • Stage transitions auto-marked when reviewer advances
  • Manual override of computed stage (rare) by replay center lead

Configurable Controls

  • Stage clock alert thresholds (default 60s warn, 90s critical)
  • Auto-notify on-field referee at threshold (on by default)
  • Visible reviewer detail (name vs initials vs replay center only)
  • Sort order (elapsed time default · game · stage)

Permissions & Audit

SEC office + Replay Center roles full view. Schools see replays involving their game only. Every ruling logged WORM. Reviewer assignment + manual stage override audit-logged.

01.6

Weather Radar panel

REAL-TIME

5-venue radar list with temp, condition, and alert chip. Lightning advisories auto-pulse the row and auto-create a SEV-2 incident.

Data Sources

  • NWS API — venue lat/lon to nearest forecast office, 5-min poll
  • Venue lightning detection — local sensors (Earth Networks) at all 16 FB venues + spring-sport venues, real-time
  • Venue temp — pulled from NWS observation station nearest the venue

Manual Inputs

None. Fully automated. Manual incident closure (after weather clears) entered in Incidents.

Configurable Controls

  • Venue list (default = today's hosting venues, can pin always-on venues)
  • Lightning advisory auto-open SEV (default SEV-2, range SEV-1 to SEV-3)
  • Hold duration default (NCAA standard 30 min · admin can override)
  • Temperature unit (°F default, °C selectable)

Permissions & Audit

All SEC roles + Event Staff view. Lightning advisories auto-write to audit + auto-create incident with link. Hold-extend actions by on-duty audit-logged.

01.7

Active Incidents panel

REAL-TIME

List of open incidents across the conference with category icon, severity, description, and elapsed time. Click to open Incident Desk.

Data Sources

  • Incidents module — all open + monitoring incidents
  • Auto-created by: NWS lightning (WX), Social Listening Tier-2 (PR), Replay center comms loss (Tech)
  • Manually created by: on-duty coordinator (Med, Sec, Tech, etc.)

Manual Inputs

  • Incident category (Medical / Security / Weather / Technical / PR / Facility)
  • Severity (SEV-1 / SEV-2 / SEV-3 / SEV-4 / SEV-MON)
  • Description text + venue + linked game
  • Owner assignment
  • Resolution note on close

Configurable Controls

  • Default sort (severity default · elapsed · category)
  • Auto-collapse SEV-4 + MON (on/off)
  • Time-to-acknowledge alert threshold (default 5 min)
  • Visible categories (toggle each)

Permissions & Audit

SEC office + Event Staff full view. Schools see incidents at their venue. Every incident is WORM-logged with full chain-of-action.

01.8

Broadcast Status panel

EVENT

Every broadcast window today by partner (CBS · ABC · ESPN · SECN · SECN+) with on-air status: ON / HALF / UP NEXT / CLOSED.

Data Sources

  • Partner ops feeds — CBS / ABC / ESPN ops teams push status to a shared broadcast_windows table
  • SECN/SECN+ — direct integration, real-time
  • Backup — Media Hub manual entry by SEC partner liaison

Manual Inputs

  • Partner ops marks "ON AIR" at window start
  • SEC liaison can override status (used during feed loss)
  • Window definition entered weeks ahead in Scheduling

Configurable Controls

  • Partner list (which networks shown, default = today's active)
  • Show streaming windows alongside linear (SECN+ on/off)
  • Auto-flag feed-loss incident when status hung > 5 min

Permissions & Audit

SEC office + Media Partner role full view. Status overrides logged. Schools see windows involving their games.

01.9

Crew Grading (live)

REAL-TIME

Provisional live grade for each on-field crew today. Number turns yellow under 88. Yellow flag in Officials module + auto-routes to incident desk under defined thresholds.

Data Sources

  • AI overlay (computer vision) — spot accuracy, penalty-correctness flags, pace
  • Coordinator notes — live additions from sport coordinator on duty
  • Replay disagreement rate — replay center, real-time
  • School complaint signals — Film Portal submissions this game

Manual Inputs

  • Coordinator can adjust per-game grade ±2 with comment
  • Final grade locked 24h after game by Coordinator of Officiating

Configurable Controls

  • Component weights (default 35/25/15/15/10, admin-tunable)
  • Threshold colors (high ≥ 95 default, warn ≤ 88 default)
  • Auto-incident on grade drop (under 85 mid-game default)
  • AI overlay confidence floor (default 80%, lower = more flags)

Permissions & Audit

VP Officiating + Sport Coordinators full view + adjust. Other SEC roles view-only. Schools see grade for crew on their game only. Every adjustment logged with comment + actor.

01.10

Field Communications feed

REAL-TIME

Filtered live message feed from crew + replay channels (operational message types only — no chat).

Data Sources

  • Comms Hub — pulls from sport's crew channels + replay channels
  • Filtered to message types: Replay status · Crew confirmation · Incident note · School request

Manual Inputs

All entries are user messages in Comms Hub by crew refs, replay officials, school liaisons. Nothing input directly from Ops Center.

Configurable Controls

  • Message type filter (toggle each type)
  • Sport scope (default current sport · all sports)
  • Max items shown (default 6 · range 4-12)
  • Auto-translate non-English (off by default)

Permissions & Audit

SEC office full view. Schools see only messages from their game's crew. Replay channels viewable by SEC + Replay roles. Audit handled by Comms Hub (this is just a read filter).

01.11

Mini-feed ("What changed in last 2 min")

REAL-TIME

Bottom-right floating widget, auto-updates every 25s with state changes across the page. Collapsible. Persists across game-row clicks.

Data Sources

  • Composer event stream — same WebSocket feeds as the other panels, aggregated
  • Includes: score changes, replay rulings, incident open/close, weather flips, school requests received

Manual Inputs

None — pure read.

Configurable Controls

  • Auto-refresh interval (default 25s, range 10s-60s)
  • Max items held (default 8, range 5-20)
  • Default state (collapsed vs. expanded on load)
  • Position (default bottom-right, options BL/TR/TL)
  • Visible event types (toggle each)

Permissions & Audit

All SEC roles. School-scoped users get school-scoped events. No audit (read-only).

01.12

Wall Mode + Audio toggle

USER

Wall Mode strips chrome and auto-rotates between game board (45s) and conference map (15s) for the 4K monitor in the conference office. Audio toggle plays chimes for critical events.

Data Sources

No new sources — uses everything else on the page. Map view pulls venues + pin types from Incidents module.

Manual Inputs

  • Toggle Wall Mode button or Esc to exit
  • Audio toggle (off by default)
  • Per-event audio type selection in settings

Configurable Controls

  • Rotation intervals (default 45s board / 15s map · admin tunable)
  • Rotation order (default board first · selectable)
  • Audio events (SEV-1 alert, SEV-2 alert, score change, replay overdue — each toggleable)
  • Audio volume default (50%)
  • Persistent across browser reload (on by default for the wall-display browser)

Permissions & Audit

Wall Mode toggle: any SEC role can activate locally. Audio configuration: Sport Admin+. No audit (presentation mode).
