Module 03 · Operator Reference

Film & Complaint Portal.

Two-sided system of record. Schools write; SEC office rules. Video lives in Mux; metadata + threads in Postgres; archived rulings in WORM storage. Below: every visible section, every input, every control.

03.1

Stage-grouped Review Queue

EVENT

5 sections (New · In Review · Awaiting School · Replied · Archived) with count, avg time-in-stage, and SLA pressure bars per row.

Data Sources

  • submissions table — one row per school complaint
  • Stage = computed from latest event in submission's audit trail
  • SLA color = (deadline - now) / SLA window

Manual Inputs

  • School submits via School Portal Quick-Submit or Film Portal page
  • Reviewer claim (moves to In Review)
  • Reviewer reply (moves to Awaiting School)
  • School ack (moves to Replied)
  • Reviewer promote-to-training (moves to Archived)

Configurable Controls

  • SLA window per priority (default A=72h, B=120h)
  • SLA pressure thresholds (warn at 50%, danger at 80%, overdue at 100%)
  • Stage section order (default New first)
  • Auto-archive after N days closed (default 30)

Permissions & Audit

SEC officiating roles full. Schools see own submissions. Every stage transition WORM-logged.

03.2

Bulk-action checkboxes + bar

USER

Hover-reveal checkbox on each row; sticky gold bar slides up when any selected. Send Memo Template / Archive / Reassign Reviewer / Mark Resolved.

Data Sources

Reads submission IDs from DOM selection; mutations go through standard submission API endpoints.

Manual Inputs

  • Click checkbox to add to selection
  • Action button to perform bulk operation

Configurable Controls

  • Which bulk actions available per role
  • Confirmation modal threshold (default 5+ items)
  • Auto-clear selection after action (default on)

Permissions & Audit

SEC reviewer roles only. Each bulk action writes one audit row per affected submission.

03.3

Video player + annotation toolbar

USER

Frame-step, playback speed (¼×–2×), angle switcher (Wide/Endzone/All-22/Sideline), loop, annotation tools (circle, arrow, freeze, measure, note).

Data Sources

  • Video file — Mux-hosted HLS stream, frame-accurate seeking
  • Per-clip: multiple angle assets stored separately
  • Annotations — JSON in clip_annotations keyed by clip_id + timestamp_ms

Manual Inputs

  • School uploads clip (transcodes to HLS + extracts thumbnails)
  • School/reviewer draws annotations
  • Reviewer can add additional angles if available

Configurable Controls

  • Available angles per submission type
  • Annotation persistence (save as private vs share with school)
  • Default speed (1× default)
  • Frame-step interval (default 1 frame = 1/30s)

Permissions & Audit

School draws on their own submissions; reviewer can draw + edit. Final annotations frozen on submission close. Each annotation create/edit logged.

03.4

Labeled scrub markers

USER

Per-clip labeled markers (Contact 0:08 · Holding window 0:18 · Ball thrown 0:28) — clickable to seek; hover for label.

Data Sources

  • clip_markers table — clip_id, timestamp, label, type
  • Standard markers per call-type (auto-suggested)

Manual Inputs

School or reviewer drops marker at current frame and labels it. Standard markers per call-type pre-populate.

Configurable Controls

  • Standard marker templates per call-type (admin-editable)
  • Max markers per clip (default 8)
  • Marker label vocabulary (controlled list)

Permissions & Audit

School + Reviewer can add. Locked on submission close. Adds logged.

03.5

AI-Suggested Ruling card

EVENT

Auto-drafted ruling suggestion with confidence %, 3 cited similar past clips, and suggested template. Reviewer can Accept / Edit / Override.

Data Sources

  • Embedding model — clip + tags vectorized; nearest-neighbor against archived training-library entries
  • Template library — text-snippet store keyed by call-type + outcome
  • Confidence = cosine similarity of top match

Manual Inputs

  • Reviewer clicks Accept → template inserted into reply box (still requires Send)
  • Edit Template → opens template in editor
  • Override → dismisses suggestion + logs override reason

Configurable Controls

  • Min confidence to surface (default 80%)
  • Template library curation (admin-editable)
  • Auto-cite count (default 3, range 1-5)
  • Per-call-type enable/disable

Permissions & Audit

Reviewers see + act. School never sees AI suggestion. Accept/Edit/Override all logged with original suggestion text.

03.6

Similar Past Clips sidebar + Crew Impact card

EVENT

3 most-similar archived clips with match %. Crew Impact card shows what this submission means for the crew's grade.

Data Sources

  • Similar Clips — same embedding model as AI ruling
  • Crew Impact — projected grade change from Officials grading engine

Manual Inputs

None — pure read. Clicking a similar clip opens it in comparison view.

Configurable Controls

  • Number of similar clips (default 3)
  • Grade-impact display threshold (default ≥ 0.5 point)
  • Crew Impact card on/off per call type

Permissions & Audit

SEC reviewers only. Crew Impact restricted to VP Officiating + Sport Coord.

03.7

Recurring Patterns AI panel

DAILY

4 AI-clustered patterns from 30 days. Each shows confidence + memo-opportunity callout.

Data Sources

  • Submissions clustered nightly by call-type + situation + ruling outcome
  • Cluster ≥ N submissions surfaced as pattern

Manual Inputs

VP can promote a pattern to a memo workflow (writes to Comms Hub draft).

Configurable Controls

  • Min cluster size to surface (default 5)
  • Rolling window (default 30d)
  • Cluster types enabled (call-type · situation · outcome · crew)

Permissions & Audit

VP Officiating + Sport Coords. Promote-to-memo action logged.

03.8

SEC Office / School View toggle

USER

Top-of-page toggle. Switching to School View applies Auburn (or your school) scope: own submissions only, AI ruling card + Crew Impact + bulk bar hidden, stage section headers hidden.

Data Sources

Toggle drives a body class; CSS + JS filter to school-scope query.

Manual Inputs

Click toggle.

Configurable Controls

  • Which sections are SEC-only vs school-visible (admin-editable)
  • Default view on load per role (SEC = sec, School = school)

Permissions & Audit

SEC roles can preview School view. School roles cannot enter SEC view. No audit (presentation).
