Module 06 · Operator Reference

Championship Management.

Project-management surface per championship. 18 workstreams · countdown · vendors · hotels · ticketing · volunteers · joint command. System of record for "is this championship on track?"

06.1

Hero card + countdown

REAL-TIME

Big championship name + venue + date + live countdown + 4 quick stats (workstreams complete %, tickets distributed, credentials issued, event budget).

Data Sources

  • championship record (date, venue, leads)
  • Countdown computed from event date
  • Workstream % from workstreams.status aggregate
  • Tickets/creds/budget from each module's totals

Manual Inputs

Championship record created annually by Director of Championships. Lead assignments + dates entered then.

Configurable Controls

  • Which 4 stats shown
  • Countdown granularity (days vs full)
  • Hero color theme per championship

Permissions & Audit

Director of Championships + executive committee edit. SEC roles view. Field changes logged.

06.2

Workstream board (Green/Yellow/Red)

EVENT

18 workstreams per championship with status, owner, progress %.

Data Sources

  • workstreams table per championship
  • Status flips: weekly check-in missed = auto-yellow; owner-set red
  • Progress % is owner-entered

Manual Inputs

  • Owner posts weekly status (Green/Yellow/Red + % + note)
  • Director can override status

Configurable Controls

  • Workstream template per championship type (FB / MBB / WCWS / etc.)
  • Weekly check-in cadence
  • Auto-yellow rule (missed weeks threshold)
  • Escalation chain on Red

Permissions & Audit

Workstream owners edit own. Director edits any. Status flips logged. Red workstreams auto-write Incident (SEV-MON).

06.3

Volunteer Onboarding bars

EVENT

Per-role volunteer onboarding progress bars (Game Day Ops, Media Workroom, Hospitality, etc.).

Data Sources

  • volunteer_assignments joined to background_checks
  • Role from volunteer_role_targets

Manual Inputs

  • Volunteer applies via portal
  • Background check vendor returns pass/fail
  • Onboarding lead approves role assignment

Configurable Controls

  • Role targets (volunteers needed per role)
  • Background-check requirements per role
  • Auto-reassign on background fail (default move to non-restricted)

Permissions & Audit

Onboarding lead edit. Volunteer roster view to championship team. All assignments logged.

06.4

Hotel Block tracking

DAILY

Per-property pickup percentage with release-deadline countdown.

Data Sources

  • Property manager APIs (per-hotel) — nightly pickup pull
  • Block contracts in hotel_blocks

Manual Inputs

  • Block contracts entered when negotiated
  • Release decisions before deadline (release-back vs hold)

Configurable Controls

  • Release deadline alert window (default 7d)
  • Auto-release if pickup < threshold (admin-tunable per property)

Permissions & Audit

Hospitality lead. Release decisions logged.

06.5

Ticketing distribution

DAILY

Per-allotment ticket distribution (participating schools, SEC office, public, sponsors, staff comp).

Data Sources

  • Ticketmaster + Paciolan APIs
  • SEC box office direct sales
  • Mobile-wallet add-rate from ticketing partner

Manual Inputs

  • Allotment sizes set at venue contract
  • Allocations adjusted as event approaches

Configurable Controls

  • Allotment definitions per championship
  • Mobile-wallet enforcement (mobile-only vs paper allowed)
  • Gate-scan readiness alerts

Permissions & Audit

Ticketing lead. All allocations logged.

06.6

Security / Joint Command (JOC)

EVENT

Multi-agency coordination roster (SECP, local PD, state, FBI liaison, venue, EMS). DHS NTAS, threat posture, walkthrough rehearsal.

Data Sources

  • JOC roster (per-agency confirmations)
  • DHS NTAS feed
  • Threat assessment from intel partners
  • Crisis-comms templates from Incidents module

Manual Inputs

  • Agency confirmations entered as received
  • Walkthrough rehearsal date set
  • Pre-staged crisis-comms templates

Configurable Controls

  • JOC member list per event type
  • Threat-level alert thresholds
  • Rehearsal cadence

Permissions & Audit

Head of Security + Director of Championships. Joint-command-only channels in Comms Hub. WORM-logged.
