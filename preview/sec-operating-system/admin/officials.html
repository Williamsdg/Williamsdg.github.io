Module 02 · Operator Reference

Officials & Replay.

Unlike Ops Center, this is a system of record. Crew assignments, grades, replay decisions, travel — all born here. Every section below tells you what data flows in, what the Coordinator of Officiating types in, what an admin can tune, and who can see or change it.

02.1

Sticky deadline banner

EVENT

Yellow banner that appears when any officials confirmation is within 24h of the Wednesday deadline.

Data Sources

  • assignments table — pending confirmations + their deadlines
  • Rule: any pending where deadline - now < 24h

Manual Inputs

  • Coordinator publishes assignments Sunday (creates pending rows)
  • Officials click "Confirm" in mobile app (clears pending)
  • "Send Reminders" CTA = bulk reminder action

Configurable Controls

  • Deadline day (default Wednesday, range Mon-Fri)
  • Banner trigger window (default 24h, range 6h-48h)
  • Auto-send first reminder at 48h (on/off)
  • Escalate to VP at 12h (on/off)

Permissions & Audit

VP Officiating + Sport Coordinator can dismiss. Reminder send action logged.

02.2

Live Crews "right now" panel

REAL-TIME

8-card grid of every on-field crew today with current game, score, D&D, replay status, and live game grade. Cards animate yellow on grade dip.

Data Sources

  • Crew assignments — assignments table
  • Game state — Genius Sports feed (D&D, quarter)
  • Replay status — replay center system
  • Live grade — grading engine real-time output

Manual Inputs

None. Card click opens Crew Profile drawer (read-only).

Configurable Controls

  • Grade-alert threshold (default 88, range 80-92)
  • Auto-refresh interval (default 15s)
  • Max cards per row (default 4)
  • Sort (status default · grade · game start)

Permissions & Audit

VP Officiating + Sport Coords full view. Other SEC roles view. Schools see their game's crew only.

02.3

Saturday Crew Board · 7-column row

EVENT

Main crew table: Crew name + chemistry · Assignment · Postseason badge · Complaint dot · Travel risk · Grade · Action.

Data Sources

  • Crew chemistry — computed from how many weeks the 7 officials worked together this season
  • Postseason — rule-engine output (≥ 90 YTD = bowl, ≥ 92 = SECCG, ≥ 88 = review)
  • Complaints — Film Portal count per crew this season
  • Travel risk — WX + segment count + connection count

Manual Inputs

  • VP Officiating publishes assignments → board populates
  • Crew chemistry auto-computed; admin can pin chemistry override

Configurable Controls

  • Postseason thresholds (per-eligibility, per-sport tunable)
  • Complaint dot threshold (default ≥ 1 unresolved)
  • Travel risk weights (WX 0.5, segments 0.3, connections 0.2 default)
  • Column order + visibility (drag-to-reorder)

Permissions & Audit

VP Officiating + Sport Coords edit. SEC office view. Schools see only crews on their games. Every assignment change WORM-logged.

02.4

Grade-breakdown hover popover

USER

Hover any grade cell → popover with 4 components (spot accuracy, penalty correctness, game management, replay calibration) + 10-game sparkline each.

Data Sources

  • Component scores — grading engine, weighted as configured
  • Sparkline data — last 10 game-by-game scores from crew_grades
  • Composite — weighted aggregate of components

Manual Inputs

Components are AI-computed but Coordinator can override any single-game score with comment within 24h of game.

Configurable Controls

  • Component weights (default 35/25/15/15 + 10 complaint, admin-tunable)
  • Sparkline range (default 10 games, range 5-20)
  • Color cutoffs per component

Permissions & Audit

VP Officiating + Sport Coords adjust. All SEC roles view. Schools see only their crews. Every adjustment audit-logged.

02.5

Replay Disagreement Alert

REAL-TIME

Yellow alert when a replay center overturns a single crew 25%+ in a single game. Auto-routes to Incidents as SEV-MON.

Data Sources

  • Per-game replay log — overturn rate computed live
  • Crew + replay center pair tracked

Manual Inputs

None — fully automated.

Configurable Controls

  • Threshold (default 25%, range 15-40%)
  • Minimum reviews to trigger (default 3, prevents 1-of-2 noise)
  • Auto-route incident severity (default SEV-MON)

Permissions & Audit

VP Officiating + Replay leads. Alert + auto-incident logged.

02.6

Grading AI · Anomalies panel

DAILY

4 AI-detected anomalies per week with confidence %. Missed-call patterns, overturn trends, exemplary plays, postseason locks.

Data Sources

  • AI overlay model — trained on prior season grading + film library
  • Per-crew rolling-window analysis (default 30 days)
  • Compared against season + position-group baseline

Manual Inputs

  • VP can mark anomaly as "acted on" (closes the suggestion)
  • VP can promote anomaly to refresher-memo workflow

Configurable Controls

  • Min confidence to surface (default 85%)
  • Max anomalies shown (default 4)
  • Rolling window (default 30d, range 14-90d)
  • Anomaly types enabled (missed-call · overturn-trend · exemplary · postseason-lock)

Permissions & Audit

VP Officiating + Sport Coords full. Other roles can view but not act. Every "acted on" or "dismiss" logged.

02.7

Crew Profile drawer

EVENT

Side-drawer crew profile: KPI tiles · composite breakdown · recent schedule · 7-man roster with individual grades · active complaints.

Data Sources

  • Crew record · officials roster · per-official grades
  • Schedule — joined from Scheduling module
  • Complaints — Film Portal joined by crew_id

Manual Inputs

  • Send Memo button → drafts a memo addressed to this crew
  • Open in Film Portal → filtered Film Portal view
  • Full Profile → multi-page detail (not in MVP)

Configurable Controls

  • Default tab (KPIs default · Roster · Schedule)
  • Roster display (initials vs full name vs full name + grade)

Permissions & Audit

VP + Sport Coords full edit. Other SEC view. Schools see crew only on their game. Send Memo action logged + triggers Comms Hub thread.

02.8

8-week Assignment Heat Map

EVENT

Visual grid of every crew × next 8 weeks (Wk 12 → CFP). Cells colored by assignment density. Over-assignment auto-flagged red.

Data Sources

  • assignments table — every crew × every game
  • Sport schedule from Scheduling module

Manual Inputs

  • Click any cell to drill into game assignment + edit
  • Drag-and-drop reassignment (held to admin role)

Configurable Controls

  • Over-assignment rule (default 2 games in 5 days)
  • Week range (default 8, range 4-16)
  • Bye highlighting (on/off)

Permissions & Audit

VP + Coords edit. All SEC view. Any drag-reassign WORM-logged.
