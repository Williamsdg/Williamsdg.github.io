What to change in iPage

Three records, then the nameservers. Each value has a Copy button beside it.

Step 1 — set these three records

In the iPage DNS editor for cornerstoneadj.com.

RECORD 1 — TYPE A

Host @ (shown as blank or as the domain itself), one value:

75.2.60.5

RECORD 2 — TYPE CNAME

Host www, pointing at:

cornerstone-claims.netlify.app

RECORD 3 — TYPE MX

Host @, priority 10, pointing at:

mx.accountsupport.com

This is the email record. If iPage already has it and it reads exactly as above, leave it as it is.

Step 2 — then switch the nameservers

Once those three are saved, change the domain off the two Wix nameservers to iPage's own — your panel will fill those in. Doing it in this order means the email record is already in place when the switch happens.

That's it

To put it back

Set the nameservers to these two and everything returns as it was:
