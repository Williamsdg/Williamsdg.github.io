One record to add

Kerissa is moving the Cornerstone email over to Google. Before that can be set up, Google needs proof that the business owns the domain — which is one short text record added to the DNS.

THIS DOES NOT TOUCH THE EMAIL

A record of this type carries no routing — it is only a label that proves ownership. Mail keeps flowing exactly as it does today, to exactly the same place.

Nothing else on the account changes, and the switch-over itself is a separate job on a separate evening, arranged with Kerissa.

PLEASE ADD ONLY — DON’T EDIT OR DELETE

Leave every existing row exactly as it is, the MX row above all

The MX row is what delivers their mail. If it is changed or removed, email stops arriving straight away and no warning is given. This job only adds one new row to what is already there.

The one step

  1. Add a new record of type TXT.

    For the name or host, use the root of the domain. In most panels that is typed as:

    @

    Some panels label this “Host”, some “Name”. If it will not accept @, leave the box empty — that means the same thing. Do not put www here.

  2. Paste this as the value:
    google-site-verification=Y1jpYsIljkAcaGsK7Y1K7CFBhdjHc3GQQTcgyQ0BAdo

    It must be copied whole, exactly as it reads, with no spaces added and nothing trimmed off either end. Use the Copy button rather than retyping it.

    PLEASE CHECK IT SAVED WHOLE

    Some panels cut a long value short without saying so

    After saving, look at the value again. It should begin google-site-verification=Y1jp and end with BAdo, with 43 characters after the = sign. If it stops early, the panel has trimmed it — delete the row, paste it again, and if it still will not hold the whole thing, use the CNAME below instead and let Dylan know.

  3. Save, and leave the TTL at whatever the panel suggests.

    That is the whole job.

If the panel refuses a second TXT on that row

A few panels only allow one. If that happens, this alternative does the same job — add it as a CNAME instead, with this as the name:

ap2mvnr2u6aj

and this as the value it points to:

gv-yqsd2tr7n5wc3d.dv.googlehosted.com

Only one of the two is needed — the TXT above is the simpler option, so try that first.

Then you’re done

Send Dylan a note once it is saved and he will confirm Google has picked it up. It is usually minutes, occasionally a few hours. Nothing needs watching at your end.
