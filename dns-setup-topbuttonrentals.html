How to Add in GoDaddy

1
Log into GoDaddy → My Products → click topbuttonrentals.com → DNS
2
Find any existing A record with Name @ that points to "Parked" → click Edit → change the Value to 76.76.21.21 → Save
3
Find any existing CNAME for www → Edit it → change the Value to cname.vercel-dns.com. If it doesn't exist, click Add New Record.
4
Click Add New Record for each of the 3 email records (DKIM, MX, SPF). Copy the Type, Name, and Value exactly as shown above.
5
After all records are added, wait 5–30 minutes for DNS to propagate. The website and email will go live automatically.
Important: Copy and paste the values exactly — especially the DKIM key when you get it from Resend. Don't add any extra spaces or change any characters. If an existing A record for @ already exists, edit it rather than creating a duplicate. Vercel will automatically issue an SSL certificate once the DNS records are verified.
Stripe Webhook Setup
!
Why This is Needed
Automatically marks listings as paid when customers complete checkout

When a property owner pays the $30/mo subscription, Stripe sends a webhook to Top Button Rentals. This webhook updates the listing status from "unpaid" to "paid" so it appears on the public site. Without this webhook, you'll have to manually mark every listing as paid in the admin dashboard.

How to Set Up the Stripe Webhook

1
Log into your Stripe Dashboard → go to Developers → Webhooks
2
Click Add endpoint (top right)
3
Endpoint URL: paste https://topbuttonrentals.com/api/stripe-webhook
4
Description: "Top Button Rentals — Payment Status Updates"
5
Under Select events to listen to, click + Select events and add these two:
  • checkout.session.completed — fires when someone first subscribes
  • invoice.paid — fires every month on renewal
6
Click Add endpoint to save
7
Click on the webhook you just created → click Reveal signing secret → copy the value (starts with whsec_...)
8
Send the signing secret to Dylan at dylan@williamsdigital.io so it can be added to the Vercel environment variables. Treat it like a password — never share it publicly.
What you'll also need to send Dylan: The Stripe secret key from Developers → API Keys → Secret key (starts with sk_live_...). This is required so the webhook can verify payments. Again, treat it like a password.
