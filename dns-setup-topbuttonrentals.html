DNS Setup Instructions

Add these records in GoDaddy for topbuttonrentals.com

Website (Vercel)
1
Website Hosting (A Record)
Points topbuttonrentals.com to Vercel's servers
TypeNameValue
A@76.76.21.21
2
WWW Subdomain (CNAME)
Points www.topbuttonrentals.com to Vercel
TypeNameValue
CNAMEwwwcname.vercel-dns.com
Email (Resend)
3
Email Verification (DKIM)
Verifies topbuttonrentals.com can send emails
TypeNameValue
TXTresend._domainkey[Copy from Resend dashboard after adding domain]
4
Email Routing (MX)
Routes outgoing emails from topbuttonrentals.com
TypeNameValuePriority
MXsendfeedback-smtp.us-east-1.amazonses.com10
5
Email Authentication (SPF)
Prevents emails from going to spam
TypeNameValue
TXTsendv=spf1 include:amazonses.com ~all

How to Add in GoDaddy

1
Log into GoDaddy → My Products → click topbuttonrentals.com → DNS
2
Find any existing A record with Name @ that points to "Parked" → click Edit → change the Value to 76.76.21.21 → Save
3
Find any existing CNAME for www → Edit it → change the Value to cname.vercel-dns.com. If it doesn't exist, click Add New Record.
4
Click Add New Record for each of the 3 email records (DKIM, MX, SPF). Copy the Type, Name, and Value exactly as shown above.
5
After all records are added, wait 5–30 minutes for DNS to propagate. The website and email will go live automatically.
Important: Copy and paste the values exactly — especially the DKIM key when you get it from Resend. Don't add any extra spaces or change any characters. If an existing A record for @ already exists, edit it rather than creating a duplicate. Vercel will automatically issue an SSL certificate once the DNS records are verified.
Note for DKIM record: The DKIM value is generated uniquely when a domain is added in Resend. Dylan will provide the full DKIM key value once the domain is added in the Resend dashboard.
