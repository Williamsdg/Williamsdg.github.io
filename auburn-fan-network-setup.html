auburnfannetwork.com Setup

Quick checklist to point the new domain at buyauburn.com so it redirects automatically. About 10 minutes of clicks, then ~30 min of DNS wait time.

0 of 0 done
Step 1 — In Vercel
vercel.com/dashboard → buy-auburn project
Open Settings → Domains and click Add
Add auburnfannetwork.com
Add www.auburnfannetwork.com
Copy the DNS values Vercel shows on the next screenAn A record value for the apex, a CNAME target for www. Leave this tab open — you'll paste these into GoDaddy next.
Confirm buyauburn.com still has the "Primary" badgeIf not, click the ⋮ menu next to it → "Set as Primary Domain."
Step 2 — In GoDaddy
My Products → auburnfannetwork.com → DNS
Delete any default A record on @ that GoDaddy createdIt points to a GoDaddy parking page and will conflict.
Delete any default CNAME on www that GoDaddy created
Add the two records Vercel gave youReference values below — but the CNAME target is unique to your domain, so use the copy button on Vercel's screen to grab the exact value.
TypeNameValueTTL
A@216.150.1.11 hour
CNAMEwww[copy from Vercel — unique per domain]1 hour
Save
Step 3 — Wait + Verify
DNS usually propagates in 5–30 minutes
Both domains show ✅ "Valid Configuration" back in Vercel
SSL certs auto-issued — green padlock shows in browser
https://auburnfannetwork.com redirects to https://buyauburn.com
https://www.auburnfannetwork.com redirects to https://buyauburn.com
auburnfannetwork.com/directory.html redirects to buyauburn.com/directory.htmlPath is preserved on every redirect — confirms it's working right.
Heads up
  • No code changes or redeploys needed — this is all dashboard + DNS.
  • The CNAME target Vercel gives you is unique per domain (looks like 2ab0f90b0ae4747e.vercel-dns-017.com.). Always copy it from your Vercel screen rather than typing it out.
  • Only touch DNS for auburnfannetwork.com in GoDaddy. Leave the buyauburn.com DNS settings alone — the live site already works and shouldn't be changed.
  • If DNS is still "Invalid" after a few hours, double-check there are no leftover GoDaddy parking records on @ or www.
