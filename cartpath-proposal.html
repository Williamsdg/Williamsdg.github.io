01 — Scope of Work

What We're Building

A complete private membership platform — mobile app, web presence, backend infrastructure, and third-party integrations — designed for CartPath ATL's founding launch.

Pitch Site & Live Scores

Premium marketing site with animated clubhouse loading screen, ATL athlete roster, coaches section, community feed, merch showcase, and a dedicated Masters-style live tournament scores page.

Mobile Application

Cross-platform app (iOS + Android) built with Expo/React Native. 15+ screens including auth, roster browsing, coach profiles, booking flow, community feed, live PGA scores, and member profiles.

AWS Backend

Enterprise-grade infrastructure on Amazon Web Services. Cognito authentication, RDS Postgres database, S3 storage for photos/video, AppSync real-time feed, API Gateway, and CloudFront CDN.

Integrations

SportsData.io Golf API for live PGA leaderboards and player headshots. Chat system with real-time messaging. Photo/video upload pipeline. Push notifications for athlete availability alerts.
